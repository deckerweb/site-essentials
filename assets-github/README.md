# Site Essentials artwork

[Deutsch](README-de.md)

The PNG and SVG files use the approved slider artwork. English and German banners share the same layout. GitHub banners are 1280 × 640 and 2560 × 1280 pixels; WordPress banners are 772 × 250 and 1544 × 500 pixels. Text-free icons are available at 128, 256, 512 and 1024 pixels.

The SVG originals contain native vector shapes, gradients and DejaVu Sans text converted to paths. They contain no embedded raster images, filters, external resources or font files. The [DejaVu redistribution license](FONT-LICENSE-DejaVu.txt) is included. PNGs are exports of the same originals. Earlier visual alternatives remain in `drafts`; the top-level artwork is used by the plugin.

The icon fills its square canvas with the existing colored background; only the rounded corners are transparent. Icon geometry and colors are unchanged. Earlier padded exports are preserved in `drafts/icon-before-edge-crop-2026-10-15`.
