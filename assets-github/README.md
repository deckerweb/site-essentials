# Site Essentials artwork

Approved banners and icons, with English and German text variants. All SVGs use native vector shapes and paths, including converted lettering; there are no embedded raster images or external resources. No font files are required to display them. DejaVu Sans attribution and redistribution terms are in FONT-LICENSE-DejaVu.txt. PNG exports use the approved artwork. Screenshots show the neutral local demonstration of version 1.0.0 and are included only in documentation, never the installable ZIP.
