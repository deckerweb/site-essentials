# All features at a glance

[Deutsch](Funktionen) · [User guide](User-guide) · [Home](Home)

For **Site Essentials 1.1.0**. 68 feature points in twelve groups.

All features at a glance, grouped by task. You decide what to enable for your website. Three administrator checks are enabled by default; other optional modules are activated deliberately. Individual features have the limitations explained below.

## Settings & presets

- Search and filter settings, comparing drafts with saved values or presets.
- Five included presets and up to 20 custom local presets.
- Review changes before saving and selectively apply them to a draft.
- Import and export configurations and reuse saved settings on other websites.
- Transfer collections of custom presets with validation and conflict-free names.
- Review and restore the previous configuration, or deliberately prepare a startup configuration.

## Login & editors

- Hide the login language selector and periodic administrator-email prompt.
- Customize the login-logo link and description.
- Choose the Classic Editor per content type without converting existing blocks.
- Control fullscreen mode, welcome screens, the block directory, core patterns, external pattern suggestions and template editing.
- Use the classic widget interface and disable selected classic core widgets.

## Administration & lists

- Offer title-only search in content lists while keeping full search as the default.
- Show and copy post, page, media and user IDs, with sorting in supported lists.
- Selectively add featured-image, modification-date and registration-date columns.
- Record the last successful login per user and website, without IP addresses or a login history.
- Adjust toolbar entries, the greeting and admin footer; show administrators the WordPress environment.
- Hide selected tool links, block-template/font menus and writing-settings sections.

## Dashboard & client guidance

- Hide selected native dashboard widgets and the large welcome panel.
- Create one information widget with formatted instructions and links.
- Grant visibility to selected roles or individual users.
- Transfer saved widget text separately with explicit confirmation.

## Design access & classic menus

- Control access to widgets, the Customizer and classic menus by role.
- Add local access exceptions for individual users.
- Restrict native widget/Customizer pages while retaining content and frontend output.
- Duplicate classic menus with their hierarchy, native link properties and SE visibility.
- Control classic-menu item visibility and set site defaults for native menu fields.
- Remove Bricks templates and taxonomies from navigation choices; hide native Site Editor menu links for classic Bricks themes.

## Posts, blog & destinations

- Disable post administration and public blog output separately while retaining content.
- Use custom singular and plural labels for posts.
- Set alternative internal or external destinations for selected public content types.
- Use reversible redirects and new-tab/nofollow options while retaining editor and preview access.
- Import existing Page Links To destinations after review and explicit selection.

## Media library & uploads

- Show file sizes in the media list and sort by them.
- Filter PDF, Office, ZIP, OpenDocument, CSV and text files in list and grid views.
- Selectively prevent new video uploads and new PDF thumbnail generation.
- Lowercase new upload filenames and show generated image sizes in the editor.
- Explain media-trash status and manual setup without changing configuration files.
- Measure local upload storage with bounded scheduled scans, not overall hosting usage.

## Comments & local avatars

- Disable comments globally or per content type without deleting existing comments.
- Hide existing comments in normal frontend output while preserving private notes.
- Control the reply script, self-pingbacks and automatic comment-URL linking.
- Use local user images, allow permission-checked profile uploads and add an avatar column.
- Choose, upload or reset a local default avatar image.
- Prevent Gravatar requests for avatar output and defer to supported local-avatar providers.

## WordPress features & interfaces

- Adjust Heartbeat intervals per area and content type and set revision limits.
- Selectively reduce emoji assets, public Dashicons and jQuery Migrate for logged-out visitors.
- Block XML-RPC and disable public search and author archives.
- Disable automatic WordPress spelling correction and restrict the core file editor on single sites.
- Disable native core AI features and the Connectors page; independent plugin AI is outside this scope.
- Control successful automatic-update emails separately for WordPress, plugins and themes; hide core-update notices based on permissions.

## Page source, feeds & embeds

- Selectively remove generator, RSD, WLW, shortlink and REST references from page source.
- Control feed-discovery links independently of feed endpoints.
- Disable feed endpoints with a not-found response when needed.
- Control automatic URL embedding and the site’s own oEmbed offering separately.
- Remove the core fallback favicon without replacing a custom site icon.

## Maintenance & website checks

- Use a published WordPress page as the maintenance page, designed in the Block or Classic Editor.
- Preview maintenance before enabling it; visitors receive HTTP 503 while administrators retain access.
- Respect active maintenance modes from Bricks, Elementor and Breakdance.
- Show administrator checks for search-engine indexing, the privacy page and the legal-notice page.
- Acknowledge intentional choices, without automatically changing visibility or assessing legal compliance.
- Use test links for 404/no-results pages, robots.txt, sitemaps and feeds, plus an explicitly requested anonymous homepage check.

## Diagnostics, handover & Multisite

- Inspect settings, saved values and known dependencies through on-demand, data-minimizing diagnostics.
- Show PHP information, memory details and extension support to administrators only.
- Use a printable read-only view for website handover.
- Use configuration information in Site Health and contextual native navigation commands.
- Use date/time format examples, website-icon guidance and a wider Customizer CSS editor.
- Support single sites and Multisite with site-local settings; one network policy controls the login language selector.
- Import Falcon/Unbloater settings after conflict review and clean local or network plugin data separately.

## Limitations and further details

Menu visibility is not access control; maintenance is not a permanent coming-soon mode. Media remain ordinary WordPress files. Revision limits may take effect on later saves. Some features depend on permissions, theme, WordPress version or other plugins. The guide explains the details and exceptions.
